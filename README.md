# FocusFlow – Your Personal Productivity Dashboard

FocusFlow is a student productivity dashboard designed to help students organize their day, track their learning progress, and stay focused.

## Features
- Add, complete and delete tasks
- Set task priorities
- Track skill development
- Customizable focus timer
- Adjustable break timer
- Dark and light mode
- Saves data using localStorage

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
To help students build productive habits and make consistent progress towards their goals.

Made with ❤️ using HTML, CSS and JavaScript.
